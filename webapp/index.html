MediaPipe 468 3D Mesh & Eye Aspect Ratio (EAR)

Geometric facial landmark mapping and real-time vertical-to-horizontal aperture calculation.

DriveGuard initializes MediaPipe FaceMesh directly inside the browser using WebGL hardware acceleration. The neural network computes real-time 3D coordinate vectors $(x, y, z)$ for 468 high-precision facial landmarks at over 30 FPS.

For drowsiness arbitration, we isolate the 6 canonical landmark coordinates circumscribing each eye:

  • Right Eye: [362, 385, 387, 263, 373, 380]
  • Left Eye: [33, 160, 158, 133, 153, 144]

The 2D Euclidean distance $d(p_a, p_b) = \sqrt{(x_a - x_b)^2 + (y_a - y_b)^2}$ calculates the vertical eyelid span against the horizontal eye corner width:

Mathematical Formulation

$$\text{EAR} = \frac{\|p_2 - p_6\| + \|p_3 - p_5\|}{2 \cdot \|p_1 - p_4\|}$$
$\text{EAR} \ge 0.25$: Wide open & attentive gaze.
$0.20 \le \text{EAR} < 0.25$: Eyelid droop / impending fatigue.
$\text{EAR} < 0.20$: Complete eyelid closure.

PERCLOS (Percentage of Eye Closure) & State Machine

Eliminating false alarms caused by physiological blinking through temporal rolling window arbitration.

01

Blink vs Microsleep

Spontaneous human blinks last 100 to 300 milliseconds (3–9 frames at 30 FPS). An instantaneous EAR threshold alone would trigger constant false alarms. PERCLOS solves this by measuring closure density over time.

02

30-Frame Rolling Buffer

Every frame pushes a binary state $(1 = \text{closed}, 0 = \text{open})$ into a fixed $N=30$ FIFO circular buffer. If $\text{PERCLOS} = (\sum \text{closed} / 30) \times 100\% \ge 70\%$, a DROWSY WARNING state is fired.

03

60-Frame Sleep Lock

If consecutive closed frames exceed 60 straight frames (~2.0 seconds), DriveGuard bypasses window averaging and immediately latches into a continuous CRITICAL FATIGUE ALARM.

Custom CNN Deep Learning & INT8 Quantization

Trained on the Kaggle Driver Drowsiness Dataset (DDD) and quantized for zero-latency browser inference.

To cross-validate geometric eye tracking in challenging lighting conditions (e.g. low-light night driving or glare), DriveGuard incorporates a lightweight Convolutional Neural Network (CNN) trained on thousands of augmented eye images.
