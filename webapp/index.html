How The Technology Works

1 Ear Aspect Ratio (EAR)

The foundation of the detection relies on MediaPipe's WebGL-accelerated FaceMesh. This neural network identifies 468 precise landmarks across your face at 30+ frames per second directly inside your browser.

We extract 6 specific landmarks surrounding each eye and calculate the Euclidean distance between the horizontal and vertical bounds to create the EAR fraction. If the ratio drops beneath 0.25, the system flags the eye as "closed" for that frame.

2 The PERCLOS Algorithm

Closing your eyes to blink is normal. To prevent false alarms, we track an array of the last 30 frames and calculate the Percentage of Eye Closure (PERCLOS).

If more than 70% of the frames within the rolling window are flagged as closed, the state machine triggers a DROWSY alarm. If the eyes stay shut continuously for over 60 straight frames, a CRITICAL FATIGUE state is instantly reached.

3 Machine Learning Style Inference

The Dashboard consumes these real-time alarm incidents to generate a long-term Safe Driving Score.

  • If alarms trigger frequently over a short duration, the style shifts to Drowsy.
  • If critical alarms play endlessly without the user reacting or pulling over, it shifts to Aggressive/Risky.
  • The system correlates tracking time with fatigue ratios to offer proactive resting advice.
